# Radio en Ligne 🎵

Une application web progressive (PWA) moderne pour écouter vos stations de radio françaises préférées en direct. Profitez d'une expérience fluide sur tous vos appareils avec une interface élégante et intuitive.

## ✨ Fonctionnalités

### Lecture et Contrôle
- 🎧 Streaming en direct de plus de 15 stations de radio françaises
- ⏯️ Contrôles de lecture simples et intuitifs
- 🔊 Contrôle du volume avec sauvegarde des préférences
- 🎵 Affichage des informations en temps réel sur les émissions

### Personnalisation
- ❤️ Système de favoris avec persistance locale
- 📊 Suivi des stations les plus écoutées
- 💾 Sauvegarde automatique de la dernière station
- 🎨 Interface adaptative et responsive

### Fonctionnalités PWA
- 📱 Installation sur l'écran d'accueil
- 🔄 Fonctionne hors ligne pour l'interface
- 🚀 Chargement rapide et fluide
- 🔔 Notifications pour les mises à jour (à venir)

## 🎮 Utilisation

### Installation Rapide

1. Visitez l'application dans votre navigateur
2. Cliquez sur "Installer" lorsque proposé
3. Profitez de l'application comme si elle était native !

### Installation Manuelle

\`\`\`bash
# Clonez le dépôt
git clone [url-du-repo]

# Ouvrez avec un serveur local
# Par exemple avec Python :
python -m http.server 8000
\`\`\`

## ⌨️ Raccourcis Clavier

| Touche | Action |
|--------|--------|
| Espace ou K | Lecture/Pause |
| ← | Station précédente |
| → | Station suivante |
| ↑ | Augmenter le volume |
| ↓ | Diminuer le volume |
| M | Couper/Rétablir le son |

## 🛠️ Technologies Utilisées

- **Frontend**:
  - HTML5 avec API Audio
  - CSS3 avec Tailwind CSS
  - JavaScript natif
- **PWA**:
  - Service Workers
  - Cache API
  - Local Storage
- **Design**:
  - Font Awesome Icons
  - Inter Font
  - Animations CSS personnalisées

## 🔄 Persistance des Données

L'application sauvegarde localement :
- Vos stations favorites
- La dernière station écoutée
- Le niveau de volume
- Les statistiques d'écoute
- L'état de lecture
